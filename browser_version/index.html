Supported Gestures

Hover (Move Cursor)

Extend index finger only. Moves the mouse cursor smoothly.

Left Click

Pinch thumb and index finger. Clicks at the cursor location.

Position Scroll (Index + Pinky)

Show index & pinky above half screen to Scroll UP, below half screen to Scroll DOWN.

Brightness Rotation (5 Fingers)

Rotate 5 fingers clockwise to Increase Brightness, anti-clockwise to Decrease Brightness.

Screenshot

Extend thumb, index, and pinky. Saves screenshot with flash effect.

Minimize Window

Extend index, middle, and pinky (Ring folded, Thumb closed).

Maximize Window

Extend index, middle, ring, and pinky (Thumb closed).

Close Window

Extend Index & Middle fingers (V-Sign/Peace Sign). Simulates Alt+F4 to close active window.

Mute / Unmute Volume

Extend little finger (pinky) only. Toggles master audio mute/unmute.

How to run the companion:

1

Requires Python 3.9+

Install from python.org if you don't have it.

2

Download & start the companion

Download the Desktop Companion package and run it on your computer.

Download Companion Package
# After extracting the package:
# Windows
Double-click start_companion.bat

# macOS / Linux
./start_companion.sh
3

Confirm connection

Once running, click Try Live Demo. The top-left HUD will show Companion: Connected ✓ — all 20 gestures are now fully active.

Privacy: The companion listens only on 127.0.0.1 (loopback). It is physically unreachable from any other device or the internet.
